# PinWindow v3.3

Небольшая Windows-утилита, которая закрепляет активное окно поверх остальных.

## Новое в v3.3 — окно настроек

Откройте настройки двойным кликом по значку PinWindow в системном трее или через пункт **«Настройки…»**.

В настройках можно изменить:

- глобальную горячую клавишу;
- размер кнопки-булавки;
- горизонтальное и вертикальное смещение;
- цвет активной закреплённой булавки;
- отображение кнопки у активного окна;
- системные уведомления;
- автозапуск вместе с Windows.

Настройки сохраняются автоматически в:

```text
%AppData%\PinWindow\settings.json
```

## Предыдущие улучшения

- отдельный визуальный профиль для Telegram Desktop;
- прозрачный layered-overlay без цветной каймы;
- плавное перемещение через события Windows;
- восстановление кнопки после максимизации окна;
- горячая клавиша и кнопка работают одновременно.

## Запуск из исходного кода

```powershell
dotnet run
```

## Сборка одного самостоятельного EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

Готовый файл:

```text
bin\Release\net8.0-windows\win-x64\publish\PinWindow.exe
```
