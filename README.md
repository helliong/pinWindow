# PinWindow v2

Небольшая Windows-утилита для закрепления любого обычного окна поверх остальных.

## Что изменилось в v2

- Возле системных кнопок каждого подходящего окна показывается кнопка-булавка.
- Серая/белая булавка означает, что окно не закреплено.
- Синяя булавка означает, что окно закреплено поверх остальных.
- Нажатие на булавку закрепляет или открепляет окно.
- Горячая клавиша `Ctrl + Alt + T` продолжает работать.
- Кнопки следуют за окнами при перемещении и изменении размера.
- Кнопки скрываются при сворачивании и закрытии окна.
- В меню трея можно временно отключить отображение кнопок.
- Одновременно может работать только один экземпляр PinWindow.

## Запуск

```powershell
dotnet run
```

После запуска:

1. Найдите небольшую кнопку-булавку слева от кнопки сворачивания окна.
2. Нажмите её, чтобы закрепить окно.
3. Синяя кнопка означает активное закрепление.
4. Нажмите ещё раз, чтобы снять закрепление.

## Сборка одного EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

Готовый файл:

```text
bin\Release\net8.0-windows\win-x64\publish\PinWindow.exe
```

## Важно

Кнопка является небольшим overlay-окном, которое визуально размещается в строке заголовка.
Она не внедряется внутрь процессов Проводника, Firefox и других приложений.

Некоторые программы с полностью нестандартной строкой заголовка могут располагать кнопку
чуть иначе. В проекте предусмотрен запасной расчёт позиции для Firefox и Electron-приложений.
