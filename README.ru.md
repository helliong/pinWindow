PinWindow — лёгкая утилита для Windows, которая позволяет закреплять окна поверх всех остальных приложений.

Закрепить или открепить активное окно можно с помощью кнопки рядом с его заголовком, настраиваемого глобального сочетания клавиш или меню в системном трее.

## Возможности

- Закрепление поддерживаемых окон поверх остальных
- Кнопка с булавкой рядом с заголовком активного окна
- Настраиваемое глобальное сочетание клавиш
- Закрепление и открепление активного окна через системный трей
- Настройка размера кнопки
- Настройка цвета активной булавки
- Изменение горизонтального и вертикального положения кнопки
- Автоматический запуск вместе с Windows
- Системные уведомления
- Работа в фоновом режиме
- Распространение в виде одного переносимого EXE-файла
- Поддержка Windows 10 и Windows 11
- Отдельная установка .NET не требуется

## Установка

PinWindow не требует установки.

1. Скачайте последнюю версию `PinWindow.exe`.
2. Переместите файл в любую удобную папку.
3. Запустите приложение.
4. Значок PinWindow появится в системном трее Windows.

Microsoft Defender SmartScreen может показать предупреждение, поскольку приложение пока не имеет цифровой подписи.

Запускайте приложение только в том случае, если файл был скачан из официального репозитория GitHub или со страницы проекта на SourceForge.

## Использование

### Кнопка возле заголовка окна

1. Откройте приложение, окно которого необходимо закрепить.
2. Сделайте это окно активным.
3. Нажмите кнопку с булавкой рядом с заголовком окна.
4. Нажмите кнопку ещё раз, чтобы открепить окно.

Закреплённое окно будет оставаться поверх остальных окон приложений.

### Сочетание клавиш

Сделайте нужное окно активным и нажмите настроенное глобальное сочетание клавиш.

Сочетание клавиш по умолчанию:

```text
Ctrl + Alt + T
```

Сочетание клавиш можно изменить в настройках PinWindow.

### Системный трей

Нажмите правой кнопкой мыши по значку PinWindow в системном трее, чтобы:

- Закрепить или открепить активное окно
- Открыть настройки
- Показать или скрыть кнопку возле заголовка окна
- Посмотреть текущее сочетание клавиш
- Закрыть PinWindow

Дважды нажмите по значку в трее, чтобы открыть окно настроек.

## Настройки

В PinWindow можно настроить:

- Глобальное сочетание клавиш
- Отображение кнопки закрепления
- Размер кнопки
- Цвет активной булавки
- Горизонтальное смещение кнопки
- Вертикальное смещение кнопки
- Системные уведомления
- Автоматический запуск вместе с Windows

Настройки сохраняются отдельно для текущего пользователя Windows в папке:

```text
%AppData%\PinWindow\settings.json
```

## Переносимая версия

PinWindow распространяется в виде одного исполняемого файла.

Приложение не требует установщика и может запускаться:

- Из любой папки на компьютере
- С USB-накопителя
- Из папки с переносимыми программами

Автономная версия уже содержит необходимые компоненты .NET.

## Системные требования

- Windows 10 или Windows 11
- 64-разрядная версия Windows
- Около 160 МБ свободного места
- Отдельная установка .NET не требуется для автономной версии

## Проверка скачанного файла

Откройте PowerShell в папке со скачанным файлом и выполните:

```powershell
Get-FileHash ".\PinWindow-v3.3.2-win-x64.exe" -Algorithm SHA256
```

Полученное значение должно совпадать с этой контрольной суммой:

```text

```

Также можно использовать встроенную команду Windows `certutil`:

```powershell

```

## Сборка из исходного кода

### Требования

- Windows 10 или Windows 11
- Git
- .NET 8 SDK

Клонируйте репозиторий:

```powershell
git clone https://github.com/helliong/pinWindow.git
cd pinWindow
```

Запустите приложение в режиме разработки:

```powershell
dotnet run
```

Создайте автономную релизную сборку:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Готовый исполняемый файл будет находиться в папке:

```text
bin\Release\net8.0-windows\win-x64\publish\
```

Также можно использовать включённый в проект скрипт публикации:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```
